# MaterialPhotoViewer 物料照查看器

## 使用要求

- Windows 7 SP1 或更高版本（x64）
- 单文件版，自带 .NET 8 运行时，**无需安装任何环境，双击即用**

## 功能特性

- 按物料编码前缀自动分类（品名/规格维度）
- 编码模糊搜索（允许省略 UL/度数/mm 等后缀）
- 图片缩放、平移、适应窗口
- 一键打开对应图纸文件
- 多语言界面：简体中文 / English / Tiếng Việt（越南语）
- 授权管理：首次运行赠送 180 天全功能免费试用
